# 테마보드 — 실제 배포 가능한 백엔드 스캐폴드

지금까지 채팅에서 만든 화면 프로토타입을 실제로 작동하는 Next.js 프로젝트로 옮긴 버전입니다.
이 프로젝트는 서버(Vercel)에 올려야 진짜 데이터가 뜹니다 — 이 폴더 자체를 그냥 열어서는 안 돌아가요.

## 지금 실제로 작동하는 것

- **테마 둘러보기 페이지**: 우리가 만든 진짜 데이터(109개 테마, 1,021개 종목)를 씁니다.
- **실시간(전일 종가) 시세**: `/api/stocks`가 서버에서 KRX API를 직접 호출해서 진짜 가격을 가져옵니다. (배포 후 환경변수 설정 필요)
- **금 시세**: `/api/gold`가 gold-api.com에서 실시간으로 가져옵니다. (키 필요 없음)

## 아직 샘플인 것

- **홈 화면 뉴스**: `lib/sampleNews.js`에 있는 고정된 예시 4개입니다. 실제 뉴스 수집 + AI 매칭 파이프라인은 다음 단계에서 만듭니다.
- **뉴스에 붙는 종목 등락률**: 뉴스 샘플에는 아직 실시간 가격이 안 붙어있어요 (테마 페이지에는 붙어있습니다).

## 폴더 구조

```
app/
  page.js            홈 (뉴스 피드)
  themes/page.js      테마 둘러보기
  api/stocks/route.js  KRX 시세 서버 프록시 (여기가 핵심 — CORS 문제를 서버에서 우회)
  api/gold/route.js    금 시세 서버 프록시
components/            공용 UI 조각들
lib/themeData.js       진짜 테마-종목 데이터베이스
lib/sampleNews.js       뉴스 샘플 (나중에 교체)
```

## 배포 전 꼭 필요한 것

`KRX_SERVICE_KEY` 환경변수 — 지난번에 발급받은 그 인증키(Encoding 형식, `%2F` 같은 게 포함된 것)를 그대로 씁니다.
